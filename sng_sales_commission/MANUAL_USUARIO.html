Manual de Usuario
SNG Sales Commission

Este manual explica cómo configurar y usar el módulo SNG Sales Commission para liquidar comisiones de vendedores a partir de cobros reales, reglas de antigüedad y cumplimiento de metas mensuales.

Resumen funcional
El módulo calcula la comisión cuando una factura de cliente es cobrada y conciliada. La comisión base depende del bucket de antigüedad al momento del cobro, y el monto final del mes se ajusta con una tabla de cumplimiento contra la meta del vendedor.

1. Qué necesita el usuario antes de empezar

  • El módulo sng_sales_commission debe estar instalado.
  • El módulo sales_commission_omax debe estar instalado.
  • Deben existir diarios bancarios y métodos de pago de entrada configurados.
  • Los vendedores deben existir como contactos.
  • Los clientes deben tener asignado un vendedor.

2. Cómo funciona el módulo

El módulo trabaja con esta lógica:

  1. Se emite una factura de cliente.
  2. La factura queda asociada a un vendedor.
  3. Se registra un pago y se concilia total o parcialmente.
  4. El sistema toma la fecha real de conciliación.
  5. Calcula cuántos días vencidos tenía la factura al cobrarse.
  6. Busca el bucket de antigüedad correspondiente.
  7. Calcula la comisión base sobre el monto cobrado sin IVA.
  8. Al generar la liquidación del mes, calcula el porcentaje de cumplimiento de meta.
  9. Aplica el factor de cumplimiento a la comisión bruta.

3. Configuración inicial

3.1. Configurar vendedores

En este módulo, el vendedor es un contacto res.partner.

  1. Ir a Contactos.
  2. Abrir el contacto que representa al vendedor.
  3. Marcar la opción Is Salesperson.

3.2. Asignar vendedor a los clientes

  1. Ir a Contactos.
  2. Abrir el cliente.
  3. En el campo Assigned Salesperson, seleccionar el vendedor.
Importante
La liquidación toma el vendedor desde la factura. Si la factura no tiene vendedor directo, usa el vendedor asignado al cliente.

4. Crear el plan de comisión

Ventas > Comisiones > Configuración > Planes

El plan define la vigencia y todas las reglas de cálculo.

4.1. Encabezado del plan

Complete estos campos:

  • Nombre: nombre del plan.
  • Compañía: compañía a la que aplica.
  • Moneda de liquidación: normalmente la moneda de la compañía.
  • Fecha inicio: primer día desde el que aplica el plan.
  • Fecha fin: opcional. Déjela vacía para que el plan aplique a todos los meses futuros.
Vigencia continua
Si activa un plan nuevo con una fecha de inicio posterior, el sistema cerrará el plan activo anterior el día previo.

4.2. Buckets de antigüedad

En la pestaña de buckets debe crear los rangos que determinan el porcentaje base de comisión.

Etiqueta Tipo Rango de días % comisión base
No vencido No vencido No aplica 2.00
1-45 días Vencido 1 a 45 1.50
46-60 días Vencido 46 a 60 1.00
61-90 días Vencido 61 a 90 0.50
91+ días Vencido 91 a 999 0.00

Reglas importantes:

  • Solo puede existir un bucket No vencido por plan.
  • Los buckets vencidos no pueden traslaparse.
  • Si una factura se cobra antes o exactamente en la fecha de vencimiento, entra en No vencido.

4.3. Tabla de cumplimiento

En esta pestaña se define el factor que se aplicará al total bruto mensual según el porcentaje de cumplimiento del vendedor.

% desde % hasta Factor de pago
110.00 119.9999 1.15
100.00 109.9999 1.00
95.00 99.9999 0.95
70.00 94.9999 0.50
0.00 69.9999 0.00

Después de crear el plan, use el botón Activar.

5. Registrar metas mensuales

Ventas > Comisiones > Configuración > Metas

Debe crear una meta por vendedor y por periodo.

  • Plan
  • Vendedor
  • Año
  • Mes
  • Meta
Recomendación
Registre primero todas las metas del mes y luego genere las liquidaciones. Si no existe meta, el cálculo del cumplimiento no tendrá una base correcta.

6. Operación mensual

6.1. Emitir facturas

Trabaje normalmente con facturas de cliente. La factura debe quedar publicada.

6.2. Registrar cobros

Registre pagos normalmente. El módulo toma cada conciliación parcial o total del periodo.

6.3. Generar liquidaciones

Ventas > Comisiones > Operaciones > Generar liquidaciones

Complete:

  • Plan
  • Año
  • Mes
  • Vendedores (uno o varios)

Luego presione Generar.

6.4. Revisar liquidaciones

Ventas > Comisiones > Operaciones > Liquidaciones

En la liquidación revise:

  • Meta
  • Venta real sin IVA
  • % cumplimiento
  • Factor aplicado
  • Comisión bruta
  • Comisión final

En la pestaña Detalle verá la trazabilidad por línea:

  • fecha de aplicación
  • factura
  • pago
  • cliente
  • bucket de antigüedad
  • monto aplicado sin IVA
  • comisión base
  • comisión final

6.5. Aprobar y cerrar

Cuando la revisión esté completa:

  1. Presione Aprobar.
  2. Cuando ya no se permitirán cambios, presione Cerrar.

Una liquidación aprobada o cerrada ya no se recalcula.

7. Qué significa "Requiere recálculo"

Si aparece esta marca, significa que hubo cambios en las conciliaciones después de generar la liquidación.

En ese caso:

  1. Abra la liquidación.
  2. Verifique que siga en estado Borrador.
  3. Presione Generar nuevamente.

8. Fórmulas que usa el sistema

8.1. Antigüedad

Se calcula con:

fecha_aplicación_del_pago - fecha_vencimiento_de_la_factura

8.2. Comisión base

Se calcula con:

monto_aplicado_sin_iva * %bucket / 100

8.3. Cumplimiento

Se calcula con:

venta_real_sin_iva / meta * 100

8.4. Comisión final

Se calcula con:

comisión_base * factor_de_cumplimiento

9. Manejo de moneda

Si la factura está en otra moneda:

  • el sistema conserva el monto en moneda origen
  • convierte el monto base a moneda compañía en la fecha de aplicación del pago

10. Recomendaciones para el usuario

  • No deje planes activos con vigencias que se traslapen.
  • Registre metas antes de generar la liquidación.
  • Revise las conciliaciones del mes antes de aprobar.
  • No cierre liquidaciones si todavía faltan cobros por conciliar.
  • Use el detalle para validar diferencias por bucket.

11. Limitaciones de esta versión

  • No genera factura de proveedor.
  • No genera asiento contable automático.
  • No importa metas desde Excel.
  • El proceso de pago final al vendedor se controla fuera del módulo.
