Tipo de Cambio Personalizado - Facturas Proveedor

Este módulo permite establecer un tipo de cambio personalizado en las facturas de proveedor, diferente al tipo de cambio oficial configurado en Odoo.

Características:

  • ✅ Tipo de cambio personalizado solo para facturas de proveedor
  • ✅ No afecta otros flujos de Odoo (ventas, inventario, etc.)
  • ✅ Solo visible para usuarios con permisos específicos
  • ✅ Validaciones para evitar uso incorrecto
  • ✅ Seguimiento de auditoría en los cambios

Uso:

  1. Asignar el grupo "Tipo de Cambio Personalizado en Facturas" al usuario
  2. En la factura de proveedor, marcar "Usar Tipo de Cambio Personalizado"
  3. Ingresar el tipo de cambio deseado
  4. El sistema usará automáticamente ese tipo de cambio en los cálculos

Notas:

- Solo aplica a facturas de proveedor (no clientes)
- No modifica el tipo de cambio oficial del sistema
- Los asientos contables reflejan el tipo de cambio personalizado
